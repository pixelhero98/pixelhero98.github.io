## Irregular time is part of the problem
Sensor and event streams rarely arrive on a perfect grid. Regridding can distort timing, while sequential continuous-time solvers add work as the requested horizon grows.

## One trajectory, many query times
LLapDiff learns conditional diffusion in a compact latent trajectory space. Stable complex-conjugate modes and gap-aware context support direct evaluation at requested timestamps. The same continuous-time formulation supports forecasting and missing-value imputation.

## Reading the demonstration
A damped oscillatory signal makes the query mechanism visible. Move the query timestamp and remove observations: the known synthetic trajectory can still be evaluated directly. The signal is supplied analytically; this is not a prediction from LLapDiff and observation removal does not fit a new model.
